# ⚡ Tech Trainer — Интерактивный AI-тренажёр для разработчиков

Персональное веб-приложение / PWA — интерактивный тренажёр для инженеров и программистов с автогенерацией задач локальной нейросетью.

Разработано специально для ультралегковесного хоста (Intel Celeron N3060, потребление RAM **< 30 МБ**) в связке с периодически доступным GPU-воркером (NVIDIA RTX 3060 с Ollama / Qwen 2.5:7b).

---

## 🚀 Архитектура и стек

* **Backend:** Go 1.23 (`chi` router, zero-dependency SQLite `modernc.org/sqlite` в WAL-режиме, нативные горутины).
* **AI Worker:** Smart Heartbeat каждые 4 часа + ручной запуск; контроль порога нерешённых задач (< 15 задач в категории); пакетная генерация по 50 задач; дедупликация по SHA-256 хэшу.
* **Frontend:** Vue 3 (Vite, TypeScript, Tailwind CSS, PrismJS с подсветкой кода, PWA сервис-воркер).
* **Тренажёр:**
  * Практические вопросы с выбором **от 1 до 4 правильных ответов**.
  * Подробный технический разбор решения (AI Explanation) с пояснением подкапотной логики.
  * Управление категориями задач прямо из UI.
  * Удаление некорректных задач в один клик.
  * Личный трекер: стрик, очки, точность ответов.

## 📦 Развёртывание на сервере

### 1. Клонирование и переход в каталог
```bash
git clone git@github.com:PetroProg/tech-trainer.git /home/petroprog/Projects/tech-trainer
cd /home/petroprog/Projects/tech-trainer
```

### 2. Запуск в Docker
```bash
docker compose up -d --build
```

Приложение будет доступно по адресу: `http://100.107.4.120:8080` (Tailscale) или `http://localhost:8080`.
